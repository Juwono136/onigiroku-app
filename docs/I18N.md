# Internationalization (i18n)

Onigiroku mendukung **Indonesia** dan **English** dengan `next-intl`.

## Desain

- Locale prefix: `as-needed` → `/` = ID, `/en` = English
- Messages: `src/messages/id.json`, `src/messages/en.json`
- Routing helpers: `src/i18n/routing.ts` (`Link`, `useRouter`, …)
- Request config: `src/i18n/request.ts`
- Edge proxy: `src/proxy.ts` (Next.js 16; menggantikan `middleware.ts`)

## Default locale berdasarkan region

Kunjungan pertama (belum ada cookie `NEXT_LOCALE`):

| Sinyal | Locale |
| --- | --- |
| Geo country `ID` (`x-vercel-ip-country`, `cf-ipcountry`, dll.) | `id` |
| Geo country lain (2 huruf) | `en` |
| Tanpa geo (local/dev) → `Accept-Language` `id*` | `id` |
| Tanpa geo → `Accept-Language` `en*` | `en` |
| Fallback | `id` |

`localeDetection` di middleware **dimatikan** agar `Accept-Language` tidak menimpa aturan geo/cookie di atas.

Setelah user memilih bahasa lewat switcher (ID / EN), preferensi disimpan di cookie `NEXT_LOCALE` dan dipakai di kunjungan berikutnya (mengoverride geo).

Override lokal untuk tes: set `LOCALE_REGION_OVERRIDE=en` atau `id` di root `.env` (opsional).

Implementasi: `src/i18n/region-locale.ts` + `src/proxy.ts`.

## Menambah string baru

1. Tambahkan key yang sama di `id.json` dan `en.json`
2. Pakai di Server Component:

```ts
const t = await getTranslations("nav");
t("login");
```

3. Atau Client Component:

```ts
const t = useTranslations("nav");
```

## Language switcher

Komponen: `src/components/layout/locale-switcher.tsx`

Mengganti locale tanpa kehilangan path saat ini.

## Konten Jepang

- UI ID/EN; konten pembelajaran tetap bahasa Jepang
- Font: Plus Jakarta Sans (UI) + Noto Sans JP (`font-jp`)
- Furigana/ruby: direncanakan di tahap content reader (lihat PRD)

## SEO

`generateMetadata` di `src/app/[locale]/layout.tsx` memakai namespace `meta` per locale.

Public news detail (`/[locale]/news/[slug]`) memakai `resolveMaterialSeo`: per-locale `seoTitle` / `seoDescription` dari CMS, fallback ke judul artikel + excerpt. Admin editor (visibility PUBLIC) menyediakan field SEO dwibahasa + Preview dialog — lihat [LEARNING_MATERIALS.md](./LEARNING_MATERIALS.md).

Shared URL slugs (news, lessons, learning categories, tags) always prefer the **English** label when it is filled, then fall back to Indonesian. Locale UI strings and body content stay bilingual; only the path segment is English-first.

## Namespaces penting (landing)

| Namespace | Digunakan untuk |
| --- | --- |
| `hero`, `announcements`, `features`, … | Section landing (CMS bridge) |
| `auth`, `dashboard`, `settings`, `appShell`, `localeSwitcher` | Form autentikasi + workspace peserta/admin + pengaturan + chrome dashboard + switcher bahasa |
| `notFound` | Halaman 404 branded |
| `nav` / `footer` | Chrome situs (landing / marketing) |

### Locale switcher variants

`LocaleSwitcher` mendukung `variant`:

- `pills` — segmented ID/EN (default, landing)
- `menu` — dropdown kompak
- `auto` — dropdown di layar kecil, pills dari `sm` ke atas (dipakai AppShell topbar)
